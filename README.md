# V12 Premium

مشروع Flutter أولي لتطبيق Android بتصميم أسود وذهبي وواجهة عربية.

## بناء APK من الهاتف عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد اسمه V12.
2. ارفع المجلد المخفي `.github/workflows` والملف `android.yml` أيضاً.
3. افتح تبويب Actions في المستودع.
4. اختر Build V12 Android APK ثم Run workflow.
5. بعد نجاح البناء، افتح العملية ونزّل Artifact باسم V12-release-apk.
6. فك ضغط Artifact وثبّت app-release.apk على هاتف Android.

الأقسام الحالية واجهات أولية. يلزم ربط مصادر رياضية ومكتبات فيديو ومزودي بث رسميين ومرخصين لإظهار محتوى فعلي.
